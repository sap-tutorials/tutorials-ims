Dear Tutorial Owner,

This is the second reminder to review and/or update the tutorial mentioned above. If no action is taken within sixty days, the tutorial will be retired from production.

Why are you receiving this email?

You received this e-mail because you are marked as the author for the Tutorial appearing on the subject line of this message. As such, you are the best judge of whether the Tutorial instructions are still correct.

What action do you need to take?

You have four options:

  1. Review the tutorial. If changes are required, update the tutorial using processes described in these instructions. If no changes were required, you can mark the tutorial as up to date by clicking the appropriate "Reviewed" checkbox in the IMS Tutorial Dashboard. If you mark a Tutorial as "Reviewed", the review will be noted at the next periodic processing cycle. If you perform this review on your own every 3-4 months, you will not receive these reminder messages.
  2. Designate a new Tutorial author – if you are no longer responsible for maintaining this content, you can either designate a new owner or contact the original owning team to designate a new owner. Designating a new owner requires updating or adding "author_name:" and "author_profile:" tags in the Tutorial's front matter section. You complete the process by submitting a Pull Request reflecting the change.
  3. Retire the Tutorial – in this case, you should submit a Pull Request to delete the Tutorial's directory from the Production Tutorial repository.
  4. Contact me – if something about a Tutorial makes it unclear which of the previous actions is appropriate, just contact me via e-mail and let's explore it.

If you received this message by mistake, please let us know by replying to this email.
