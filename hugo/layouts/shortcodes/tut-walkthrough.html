{{/* tut-walkthrough — renders a paired code+notes walkthrough. Receives: code (fenced code block markdown), notes (numbered list markdown). Emitted by expandDirectives when a :::walkthrough container directive is expanded. Security note: .Get values are HTML-escaped by escapeShortcodeParam before arriving here. Newlines are encoded as / by escapeShortcodeParam (Hugo's shortcode arg lexer rejects raw newlines inside a quoted param); decode them back here before markdownify so fenced code blocks and numbered lists render correctly. The | markdownify call is safe — Hugo's Goldmark renders markdown to HTML. */}} {{- $code := .Get "code" | replaceRE " " "" | replaceRE " " "\n" -}} {{- $notes := .Get "notes" | replaceRE " " "" | replaceRE " " "\n" -}}
