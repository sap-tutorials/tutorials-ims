{{/* tut-walkthrough — renders a paired code+notes walkthrough. Receives: code (fenced code block markdown), notes (numbered list markdown). Emitted by expandDirectives when a :::walkthrough container directive is expanded. Security note: .Get values are HTML-escaped by escapeShortcodeParam before arriving here. Newlines are encoded as / by escapeShortcodeParam (Hugo's shortcode arg lexer rejects raw newlines inside a quoted param); decode them back here before markdownify so fenced code blocks and numbered lists render correctly. The | markdownify call is safe — Hugo's Goldmark renders markdown to HTML. walkthrough is a CONTAINER directive, so buildShortcode always emits a closing {{% /tut-walkthrough %}} tag. Hugo rejects a closing tag on a shortcode whose template never evaluates .Inner ("does not evaluate .Inner or .InnerDeindent, yet a closing tag was provided"). The directive routes all content into the code/notes params and has no meaningful inner body, so we reference .Inner defensively — this both satisfies Hugo and renders any stray inner content. */}} {{- $code := .Get "code" | replaceRE " " "" | replaceRE " " "\n" -}} {{- $notes := .Get "notes" | replaceRE " " "" | replaceRE " " "\n" -}} {{/* Render the fenced code through Hugo's `highlight` function rather than markdownify. code-walkthrough.ts highlights per-line by selecting `.tut-walkthrough-code .line`, and Chroma's `highlight` output wraps every line in `` (noClasses=false in hugo.toml) — whereas a plain `markdownify` of the same fence emits NO per-line spans, so the click-to-highlight found zero `.line` elements and highlighted nothing. Strip the ``` fences and extract the language token from the first line. */}} {{- $codeTrimmed := trim $code "\n" -}} {{- $codeLines := split $codeTrimmed "\n" -}} {{- $lang := "" -}} {{- $body := $codeTrimmed -}} {{- if and (gt (len $codeLines) 0) (hasPrefix (index $codeLines 0) "```") -}} {{- $lang = trim (strings.TrimPrefix "```" (index $codeLines 0)) " \t" -}} {{/* Drop the opening fence line and any trailing closing fence line. */}} {{- $inner := after 1 $codeLines -}} {{- if and (gt (len $inner) 0) (eq (trim (index $inner (sub (len $inner) 1)) " \t") "```") -}} {{- $inner = first (sub (len $inner) 1) $inner -}} {{- end -}} {{- $body = delimit $inner "\n" -}} {{- end -}} {{- if eq $lang "" -}}{{- $lang = "text" -}}{{- end -}}
{{/* security-reviewed: $body is the author's fenced code content; `highlight` renders it through Chroma which HTML-escapes the source. $lang is the fence's language token (alnum). Only Chroma's fixed line/token span scaffold is emitted — no attacker-controlled HTML. */}}
{{ highlight $body $lang "" }}
{{ $notes | markdownify }}
{{- with .Inner }}{{ . }}{{ end -}}
