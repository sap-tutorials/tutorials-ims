Emitted by expandDirectives when a :::walkthrough container directive is expanded. Security note: .Get values are HTML-escaped by escapeShortcodeParam before arriving here. Newlines are encoded as / by escapeShortcodeParam (Hugo's shortcode arg lexer rejects raw newlines inside a quoted param); decode them back here before markdownify so fenced code blocks and numbered lists render correctly.
