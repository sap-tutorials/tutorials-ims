# Cloud CAP Samples

A collection of samples for the SAP Cloud Application Programming Model (CAP).

## Bookshop

A canonical CAP sample demonstrating CDS modeling, service handlers, OData v4 exposure, and Fiori Elements UI.

## Highlights

- Domain model with associations + compositions
- Service projection with `@odata.draft.enabled`
- Custom service handlers (before/on/after)
- Authentication via `@requires` annotations
