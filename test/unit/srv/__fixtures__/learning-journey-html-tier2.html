This journey teaches CAP service handlers, CDS modeling, and SAP HANA Cloud integration patterns for cloud-native business applications on the BTP platform. You will build a complete reference application from scratch.

Across 8 modules you will explore the full CAP development lifecycle, from local development with sqlite to production deployment on Cloud Foundry. Each module builds on the previous one.

By completion you should be able to deploy a production-grade CAP application with custom service handlers, hybrid local-HANA development, and CI/CD via the standard SAP MTA pipeline.
