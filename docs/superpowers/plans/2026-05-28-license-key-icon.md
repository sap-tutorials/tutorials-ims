# License Key Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a small key icon on every tutorial / mission / group surface where a tutorial requires a product license, and remove the redundant "License" text chip.

**Architecture:** Detection happens at render time, not at parse time. Hugo templates check `.Params.tags` for the literal `tutorial>license`; Vue cards check `displayTags.includes('License')`. A single inline-SVG key glyph is defined once in a Hugo partial (`partials/license-icon.html`) and once as a Vue helper component (or template literal) so both surfaces share the same look. The "License" entry is filtered out of `displayTags` chip lists on every surface so the icon stands alone. No schema changes; no parser changes; revert is a single PR revert.

**Tech Stack:** Hugo (Go templates), Vue 3 (TypeScript), Vitest (unit + smoke), inline SVG (no icon-font dependency, no `<ui5-icon>` requirement on group/mission pages).

**Spec:** [docs/superpowers/specs/2026-05-28-license-key-icon-design.md](../specs/2026-05-28-license-key-icon-design.md)
**Issue:** <https://github.com/sap-tutorials/tutorials-ims/issues/81>

## File structure

**Create:**

```ts
// Detect license-gated tutorials and filter the redundant text chip.
// The "License" string is what `humanizeTag('tutorial>license')` produces
// in scripts/parsers/render-frontmatter.ts; treat that as the contract.
export const LICENSE_TAG = 'License'

export function requiresLicense(displayTags: readonly string[]): boolean {
  return displayTags.includes(LICENSE_TAG)
}

export function visibleTags(tags: readonly string[]): string[] {
  return tags.filter(t => t !== LICENSE_TAG)
}
```
