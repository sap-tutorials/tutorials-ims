# Phase 4.4 Videos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship SAP Developers YouTube videos as the fourth new graph node type under the Phase 4 chassis. Twice-weekly cron pulls videos from the `@sapdevs` channel via YouTube Data API v3 (reusing existing credstore-backed `YOUTUBE_API_KEY`), extracts `teaches` concept links + free-form `featuresService` BTP-service tags via LLM, and surfaces videos on Phase 3 concept landing pages (with inline thumbnails) + the tutorial-OP sidebar.

**Architecture:** Three tasks landing as commit ranges on a single shared branch and a SINGLE PR (merged as squash; matches 4.2/4.3 actual shipping pattern):

1. **Chassis + YouTube corpus fetcher (Task 1)** — `Videos` + `VideoConceptLinks` + `VideoServices` entities, NEW `srv/lib/youtube-corpus-fetcher.js` (paginated full-channel iteration), `OtherResource` CDS type extended with video-specific fields, GC iteration extended, IRI prefix wired, `SHORT_BY_TYPE` updated.
2. **Cron + extraction + backfill (Task 2)** — `video-extract.js` adapter, `fetch-videos-job.js` twice-weekly cron with MAX-or-abort first-run gate, `scripts/seed-videos.cjs` one-shot backfill, projection helper, neighborhood enrichment widens to 4-array variadic merge (helper unchanged from 4.3).
3. **UI (Task 3)** — concept-page section #5 (with inline 120×68 thumbnails), sidebar `OtherResource` `'video'` widening (no sidebar thumbnail), `/build/concepts` payload extension, Hugo frontmatter pipe-through.

**Tech Stack:** SAP CAP (Node.js 20), HANA Cloud, vitest (unit + hybrid), Hugo, Vue 3 islands. YouTube Data API v3 with credstore-resolved API key; gpt-4o-mini for extraction; text-embedding-3-small for merge-on-write.

## Cross-cutting reminders for every task

- **Schema changes MUST run `npx cds build --production`** — but external-namespace artefacts go to gitignored `gen/db/src/gen/`; no tracked artefacts stage. Phase 4.1/4.2/4.3 commits show the same pattern.
- **No pre-commit hook in this repo** — no `.husky/`. Run `npx vitest run` before committing.
- **Native fetch only.**
- **No raw SQL** — except the established HANA LOB escape hatch.
- **Slug case canonicalisation** — Video slugs are `vd-<11-char-id>` (case-stable). Other slugs (`Concepts.slug`) ARE case-sensitive; keep lowercase.
- **Two link tables** — `VideoConceptLinks` (teaches, merge-on-write) + `VideoServices` (free-form, case-insensitive dedup). Mirrors 4.3.
- **`lastExtractedHash` UPDATE is the FINAL step per video** — #708 chassis pattern.
- **YouTube API key from credstore** — `resolveSecret('YOUTUBE_API_KEY', {logTag: 'fetch-videos'})`.
- **MAX-or-abort first-run gate** — cron refuses to self-bootstrap on empty `Videos`; operator must run `scripts/seed-videos.cjs` first.
