# Fix #986 — Materialize `alreadyPromoted` in KgCommunitySummaryV — Implementation Plan

> **⚠️ SUPERSEDED — do not execute this plan.**
>
> Issue #986 was fixed by **[PR #991](https://github.com/sap-tutorials/tutorials-ims/pull/991)** (merged 2026-07-05), rolled up with **#985**. The design in this plan joins on `communityId`, which shuffles across nightly Louvain re-runs (#985) — executing it would silently flag the wrong communities as promoted. PR #991 joins on a content-based `communityFingerprint` (SHA-256 of the sorted tutorial-typed member slug set) so the join is stable across re-runs.

**Goal:** Materialize `alreadyPromoted` as a real column in `KgCommunitySummaryV` via a deduplicated helper view + left join, so the Fiori `SelectionPresentationVariant #default` filter evaluates at the DB layer and the `/admin-ui/#kgCommunities` List Report doesn't render empty.

**Architecture:** Add a small `KgCommunityPromotedV` helper view over `Missions` (distinct `sourceKgCommunityId`); left-join it into `KgCommunitySummaryV` and derive `alreadyPromoted` via `case when max(p.communityId) is not null then true else false end`. Drop the `virtual null alreadyPromoted` on the AdminService projection and delete the corresponding `after('READ')` decorator in `srv/admin-service.js`.

**Tech Stack:** SAP CAP (Node.js, `@sap/cds`) · CDS views · SQLite (unit tests) · HANA (production runtime) · Vitest.

```cds
namespace com.sap.developers.ims;

// KgCommunity — per-vertex membership in a Louvain-detected community.
//
// Not @managed on purpose: TRUNCATE + INSERT is atomic inside one db.tx;
// managed timestamps would only add write noise.
//
// @cds.autoexpose: false keeps this off AdminService automatically.
// Task 6 adds two explicit @readonly projections that expose only what
// the admin tile needs.
//
// Composite PK (communityId, vertexKey): a vertex belongs to exactly one
// community per Louvain pass, so this is a natural unique key without
// carrying a synthetic ID.
@cds.autoexpose: false
entity KgCommunity {
  key communityId : Integer;
  key vertexKey   : String(280);      // matches KG_PG_VERTICES_V.VERTEX_KEY
      vertexType  : String(16);       // 'tutorial'|'concept'|'mission'|'group'|'tag'|'product'|'category'
      slug        : String(255);      // widened to max source-entity slug width
      detectedAt  : Timestamp;
}

// KgCommunityPromotedV — one row per community that has been promoted
// at least once (has any Missions row with sourceKgCommunityId=<id>).
//
// Deduplicated helper view. `KgCommunitySummaryV` left-joins this rather
// than `Missions` directly so the join stays at cardinality 1 even when
// a community has been promoted to more than one Mission (curators can
// retry `promoteCommunityToMission` with a different missionSlug).
// Without dedup, `count(*)` and `sum(...)` in the summary would double-
// count members.
//
// Fix #986: `alreadyPromoted` used to be a `virtual null` on the
// AdminService projection populated by an `after('READ')` decorator; the
// Fiori SPV #default filter therefore evaluated NULL at the DB layer and
// could render an empty List Report.
@cds.autoexpose: false
view KgCommunityPromotedV as
  select distinct
    key sourceKgCommunityId as communityId : Integer
  from Missions
  where sourceKgCommunityId is not null;

// KgCommunitySummaryV — LR-facing aggregate. Recomputed on every read;
// KgCommunity holds a few thousand rows at most, so this is free.
//
// `alreadyPromoted` is materialized here (fix #986) so the Fiori SPV
// #default filter on `AdminService.KgCommunities` evaluates against a
// real DB column instead of a NULL virtual. The left join is 1:1 by
// construction (KgCommunityPromotedV has one row per community-that-
// has-been-promoted), so `count(*)` / `sum(...)` semantics are preserved.
@cds.autoexpose: false
view KgCommunitySummaryV as
  select from KgCommunity as k
    left join KgCommunityPromotedV as p on p.communityId = k.communityId
  {
    key k.communityId,
        count(*)                                                    as memberCount    : Integer,
        sum(case when k.vertexType = 'tutorial' then 1 else 0 end)  as tutorialCount  : Integer,
        max(k.detectedAt)                                           as detectedAt     : Timestamp,
        case when max(p.communityId) is not null
             then true else false end                               as alreadyPromoted : Boolean,
  } group by k.communityId;
```

```js
// test/unit/kg-communities-already-promoted.test.js
//
// #986: `alreadyPromoted` used to be a `virtual null : Boolean` on the
// AdminService.KgCommunities projection, populated by an after('READ')
// decorator. Fiori's SelectionPresentationVariant #default filter on
// that virtual evaluated to NULL at the DB layer, potentially rendering
// an empty List Report.
//
// After the fix, `alreadyPromoted` is a real column on
// KgCommunitySummaryV, derived via left join to a deduplicated
// KgCommunityPromotedV helper view. These tests exercise:
//   1. baseline — no Missions rows → all communities have
//      alreadyPromoted=false.
//   2. one Mission → that community's row is true, others false.
//   3. odata $filter=alreadyPromoted eq false — only the non-promoted
//      communities come back.
//   4. two Missions pointing at the same community → memberCount and
//      tutorialCount unchanged (regression guard on join cardinality;
//      the whole reason KgCommunityPromotedV exists).
//   5. field control — no `virtual` metadata on `alreadyPromoted`.

import { describe, it, expect, beforeAll, beforeEach } from 'vitest';
import cds from '@sap/cds';
import { randomUUID } from 'node:crypto';

// AdminService is XSUAA-gated; cds.test in-memory mode grants mock roles
// via basic auth ('admin' user maps to a superset of authorities).
const project = cds.test('serve', '--project', '.', '--in-memory');

let db;
let KgCommunity;
let Missions;
let KgCommunities;

beforeAll(async () => {
  db = await cds.connect.to('db');
  ({ KgCommunity, Missions } = cds.entities('com.sap.developers.ims'));
  KgCommunities = 'AdminService.KgCommunities';
});

beforeEach(async () => {
  // Clean slate for each test — order matters: FK-like references first.
  await db.run(DELETE.from(Missions).where({ sourceKgCommunityId: { '!=': null } }));
  await db.run(DELETE.from(KgCommunity));
});

function seedCommunity(communityId, memberCount = 2, tutorialCount = 1) {
  const rows = [];
  for (let i = 0; i < memberCount; i++) {
    rows.push({
      communityId,
      vertexKey: `test-vertex-${communityId}-${i}`,
      vertexType: i < tutorialCount ? 'tutorial' : 'concept',
      slug: `test-slug-${communityId}-${i}`,
      detectedAt: new Date().toISOString(),
    });
  }
  return db.run(INSERT.into(KgCommunity).entries(rows));
}

async function seedMission(sourceKgCommunityId, slugSuffix = 'a') {
  return db.run(
    INSERT.into(Missions).entries({
      ID: randomUUID(),
      slug: `test-mission-${sourceKgCommunityId}-${slugSuffix}`,
      title: `Test Mission ${sourceKgCommunityId}-${slugSuffix}`,
      sourceKgCommunityId,
      missionType: 'GENERAL',
      published: false,
    })
  );
}

describe('#986 KgCommunities.alreadyPromoted materialization', () => {
  it('all rows alreadyPromoted=false when no Missions reference any community', async () => {
    await seedCommunity(101);
    await seedCommunity(102);

    const rows = await SELECT.from(KgCommunities).orderBy('communityId');

    expect(rows).toHaveLength(2);
    expect(rows.every((r) => r.alreadyPromoted === false)).toBe(true);
  });

  it('marks only the promoted community as alreadyPromoted=true', async () => {
    await seedCommunity(201);
    await seedCommunity(202);
    await seedMission(201);

    const rows = await SELECT.from(KgCommunities).orderBy('communityId');
    const byId = Object.fromEntries(rows.map((r) => [r.communityId, r]));

    expect(byId[201].alreadyPromoted).toBe(true);
    expect(byId[202].alreadyPromoted).toBe(false);
  });

  it('$filter=alreadyPromoted eq false returns only the non-promoted community', async () => {
    await seedCommunity(301);
    await seedCommunity(302);
    await seedMission(301);

    const rows = await SELECT.from(KgCommunities).where({ alreadyPromoted: false });

    expect(rows).toHaveLength(1);
    expect(rows[0].communityId).toBe(302);
  });

  it('regression guard: two Missions on the same community do NOT inflate memberCount/tutorialCount', async () => {
    await seedCommunity(401, /*members=*/ 3, /*tutorials=*/ 2);
    await seedMission(401, 'a');
    await seedMission(401, 'b');

    const [row] = await SELECT.from(KgCommunities).where({ communityId: 401 });

    expect(row.memberCount).toBe(3);
    expect(row.tutorialCount).toBe(2);
    expect(row.alreadyPromoted).toBe(true);
  });

  it('csn: AdminService.KgCommunities.alreadyPromoted is a real Boolean, not virtual', () => {
    const el = cds.model.definitions['AdminService.KgCommunities'].elements.alreadyPromoted;
    expect(el).toBeDefined();
    expect(el.type).toBe('cds.Boolean');
    expect(el.virtual).toBeFalsy();
  });
});
```
