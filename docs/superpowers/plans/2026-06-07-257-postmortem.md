```bash
  --body "$(cat <<'EOF'
## Summary

Blameless postmortem for the 2026-06-05 HDI data-loss incident filed in #257. The substantive prevention and partial-recovery work has already shipped across 5 merged PRs (#258, #259, #264, #266, #268); this PR documents what happened, what we learned, and accepts Option E (partial-recovery state) for the residual 3% reconciliation ceiling tracked in #263.

## What this lands

- \`docs/postmortems/2026-06-05-hdi-data-loss.md\` — single blameless postmortem (11 sections: summary, impact, timeline, RCA, recovery, what went well/poorly, action items, residual gap, lessons learned, see-also)
- \`docs/postmortems/README.md\` — folder index page (one row currently; establishes the folder for future postmortems)
- \`docs/.vitepress/config.ts\` — register both pages in the \`Developers > Operations\` sidebar group (predocs:build guard rejects unregistered pages)
- \`docs/developers/operations/hdi-deploy-checklist.md\` — one-line \`See also\` cross-link to the postmortem at the top

**No source code, schema, scripts, CDS, srv, or test files modified.**

## Root cause framing

Chain — necessary cause × sufficient cause:

1. **HDI hash-mismatch TABLE_REPLACE behavior** (necessary): when a \`.hdbmigrationtable\` migration version's content hash changes after deploy, HDI can fall back to drop+recreate. \`@sql.append\` was iterated 4× on 2026-06-05.
2. **Absence of a row-count tripwire** (sufficient for the data loss to go undetected): the wipe wasn't caught for hours. Fixed by PR #258/#259/#266.

## Action items table

All 8 from the postmortem; 7 done (linked to PRs), 1 open (PITR confirmation, BTP admin team).

## Residual gap

Option E accepted: 1356/1397 \`TUTORIALS.LEGACYID\` rows remain on synthetic placeholder values. The 3% IMS-reconciliation ceiling is a data-shape limit, not effort-limited. Postmortem § "Residual gap & decision" lists explicit revisit triggers.

## Closes

Closes #257.
Closes #263 (under Option E).

## Constraints respected

- ✅ Branch verified in same Bash invocation as commit per [[feedback_verify_branch_before_commit]]
- ✅ \`npm run docs:build\` passes locally (predocs:build sidebar guard)
- ✅ No CRLF regression
- ✅ Docs-only change
- ✅ Inter-doc links use markdown \`[text](path)\` format
EOF
)"
```
