- [ ] **Step 3: Extend the page-bottom telemetry IIFE**

Find the existing IIFE that handles concept-page click telemetry (it wraps `[data-kg-section="learning-journeys"]` and `[data-kg-section="tutorials"]` listeners). Add a parallel block for blog-posts:

```html
<script>
  document.addEventListener('DOMContentLoaded', function() {
    /* ... existing handlers ... */

    // Phase 4.2: blog-post link telemetry.
    var blogSection = document.querySelector('[data-kg-section="blog-posts"]');
    if (blogSection) {
      var conceptSlug = blogSection.getAttribute('data-concept-slug');
      blogSection.querySelectorAll('a[data-blog-slug]').forEach(function(a) {
        a.addEventListener('click', function() {
          try {
            window.dispatchEvent(new CustomEvent('kg.blog_post.linked_from_concept_page', {
              detail: { conceptSlug: conceptSlug, blogSlug: a.getAttribute('data-blog-slug') }
            }));
          } catch (e) { /* swallow — telemetry must not block navigation */ }
        });
      });
    }
  });
</script>
```

Match the existing IIFE's indentation + style. CSP-safe — `addEventListener` only, no inline `onclick`.

Add `formatDate` helper next to `formatLevel`:

```typescript
function formatDate(iso: string): string {
  if (!iso) return '';
  try {
    return new Date(iso).toLocaleDateString('en-US', { year: 'numeric', month: 'short', day: 'numeric' });
  } catch {
    return iso.slice(0, 10);  // fallback: YYYY-MM-DD prefix
  }
}
```

Extend `onOtherResourceClick(r)` with a `'blog-post'` branch:

```typescript
function onOtherResourceClick(r: OtherResource) {
  if (typeof window === 'undefined') return;
  if (r.type === 'learning-journey') {
    window.dispatchEvent(new CustomEvent('kg.learning_journey.linked_from_sidebar', {
      detail: {
        tutorialSlug: props.neighborhood?.tutorial?.slug,
        journeySlug: r.slug,
      },
    }));
  } else if (r.type === 'blog-post') {
    window.dispatchEvent(new CustomEvent('kg.blog_post.linked_from_sidebar', {
      detail: {
        tutorialSlug: props.neighborhood?.tutorial?.slug,
        blogSlug: r.slug,
      },
    }));
  }
}
```

Phase 4.2 keeps that pattern — no new `data-*` attribute on the anchor. The unit test in Step 12 selects the anchor by its href.
