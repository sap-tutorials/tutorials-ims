**Goal:** Add a nightly HANA GraphScript PageRank pass over `KG_PG_WORKSPACE`, materialize per-concept and per-tutorial importance scores into two sidecar tables, and multiplicatively blend the tutorial score into all four `rankNeighborhood` arms — behind `KG_PAGERANK_ENABLED` with fail-open fallback.

**Architecture:** One new GraphScript procedure `KG_PAGERANK` (sibling of `KG_SHORTEST_PATH_GRAPH`) reads the workspace and writes `ConceptRank` / `TutorialRank` sidecar tables. A new nightly job `srv/jobs/kg-pagerank-job.js` (registered at 03:53 UTC via the `runWithLock` chassis) truncates and re-fills those tables. The Node ranker in `srv/knowledge-graph-service.js` gains a `loadRankMaps()` helper (LRU-cached, 5-min TTL, single-flight) whose values are multiplicatively blended into every arm's weight when `KG_PAGERANK_ENABLED === 'true'`. Every failure mode (missing tables, empty scores, HANA errors, degenerate distributions) collapses the multiplier to `1.0` — identical behavior to flag-off.

**Tech Stack:** HANA Cloud (property-graph engine, GraphScript PageRank primitive), SAP CAP (Node.js runtime), Vitest (hybrid workspace test), `job-lock` (distributed lock), `metrics.js` (observe/gauge/counter).

**Design spec:** [`docs/superpowers/specs/2026-07-04-916-kg-pagerank-design.md`](../specs/2026-07-04-916-kg-pagerank-design.md)

**Parent spike:** [#913](https://github.com/sap-tutorials/tutorials-ims/issues/913). **Hard prereq:** [#919](https://github.com/sap-tutorials/tutorials-ims/issues/919) — `KG_PG_EDGES_V` must include `coCompletedWith` before this plan starts. **This issue:** [#916](https://github.com/sap-tutorials/tutorials-ims/issues/916).

## Task 2: Write and deploy `KG_PAGERANK.hdbprocedure`

**Goal:** GraphScript procedure that reads `KG_PG_WORKSPACE`, computes PageRank, and INSERTs per-vertex-type score rows into `ConceptRank` and `TutorialRank`. Caller (Task 4) is responsible for the `TRUNCATE` before `CALL`.

**Interfaces:**

- [ ] **Step 2.1: Create `db/src/procedures/KG_PAGERANK.hdbprocedure`.**

Replace `<PAGERANK_PRIMITIVE>` and `<PAGERANK_ARGS>` below with the exact spelling recorded in Task 0.4's notes file. If Task 0 confirmed `PAGE_RANK(:g)` with defaults, `<PAGERANK_ARGS>` is `:g`. If it requires damping + iters, use `:g, 0.85, 100`.

```sql
-- KG_PAGERANK.hdbprocedure
-- ============================================================
-- HANA GraphScript sibling for the nightly PageRank pass.
-- Computes PageRank over KG_PG_WORKSPACE and populates the
-- ConceptRank + TutorialRank sidecar tables.
--
-- CALL CONTRACT
--   IN  (none)
--   OUT (none — writes are side effects)
--
--   Caller MUST TRUNCATE ConceptRank + TutorialRank before CALL.
--   This procedure appends; it does not clear.
--
-- WHY A SEPARATE PROCEDURE (parallel to KG_SHORTEST_PATH_GRAPH)
--   HANA SQLScript does not accept inline `LANGUAGE GRAPH` blocks.
--   GraphScript is a distinct language declared at the procedure
--   boundary. The Node caller wraps TRUNCATE + CALL in a single tx
--   for atomic swap.
--
-- SIGNATURE PROBED
--   Primitive name and argument list confirmed against live DEV
--   HANA in docs/superpowers/reviews/2026-07-04-916-kg-pagerank-task0-notes.md.
--
-- Spec:  docs/superpowers/specs/2026-07-04-916-kg-pagerank-design.md
-- Issue: #916 (prereq #919)
-- ============================================================

PROCEDURE KG_PAGERANK ()
LANGUAGE GRAPH READS SQL DATA AS
BEGIN
  -- Single-arg Graph() constructor — HDI schema-local reference.
  -- Same lesson as KG_SHORTEST_PATH_GRAPH: cross-schema requires a
  -- synonym; single-schema is direct.
  GRAPH g = Graph("KG_PG_WORKSPACE");

  -- HANA GraphScript PageRank primitive. Damping alpha = 0.85 (or
  -- primitive default; see task 0 notes for confirmed signature).
  MAP<Vertex, DOUBLE> pr = <PAGERANK_PRIMITIVE>(<PAGERANK_ARGS>);

  -- Emit rows into the two sidecar tables. VERTEX_TYPE filter splits
  -- the score map by kind. INSERT-SELECT to a local table variable
  -- first (GraphScript SELECT-FOREACH doesn't accept AS aliases on
  -- projection expressions — same idiom as KG_SHORTEST_PATH_GRAPH's
  -- o_verts assignment).
  tt_concepts  = SELECT :v."SLUG", :pr[:v], CURRENT_TIMESTAMP
                   FOREACH v IN Vertices(:g)
                   WHERE :v."VERTEX_TYPE" = 'concept';
  tt_tutorials = SELECT :v."SLUG", :pr[:v], CURRENT_TIMESTAMP
                   FOREACH v IN Vertices(:g)
                   WHERE :v."VERTEX_TYPE" = 'tutorial';

  -- The two INSERTs must reference the HANA table names that the
  -- HDI-flattened `db/knowledge-graph.cds` produces. Task 1.4 verified
  -- these; do not change without re-verifying.
  INSERT INTO "COM_SAP_DEVELOPERS_IMS_CONCEPTRANK"
    (SLUG, SCORE, COMPUTEDAT)
    SELECT * FROM :tt_concepts;

  INSERT INTO "COM_SAP_DEVELOPERS_IMS_TUTORIALRANK"
    (SLUG, SCORE, COMPUTEDAT)
    SELECT * FROM :tt_tutorials;
END;
```

**Cross-check before saving:** open `db/src/procedures/KG_SHORTEST_PATH_GRAPH.hdbprocedure` and confirm the projection idiom (no `AS` on projections, `:v."VERTEX_KEY"` mixed-case column reference in quotes, single-arg `Graph()`). Adjust the code above if that file's idiom has drifted from what's written here.

- [ ] **Step 4.2: Create `srv/jobs/kg-pagerank-job.js`.**

```js
// srv/jobs/kg-pagerank-job.js
// ============================================================
// Nightly PageRank pass over KG_PG_WORKSPACE.
//
// Runs at 03:53 UTC via the runWithLock chassis in scheduler.js.
// TRUNCATEs ConceptRank + TutorialRank, then CALLs KG_PAGERANK,
// which INSERTs one row per active concept/tutorial vertex with
// its PageRank score. The three statements share one db.tx so a
// mid-run failure rolls back to yesterday's scores (fail-open).
//
// Consumed by: srv/knowledge-graph-service.js loadRankMaps() at
// request time when KG_PAGERANK_ENABLED === 'true'.
//
// Spec:  docs/superpowers/specs/2026-07-04-916-kg-pagerank-design.md
// Issue: #916
// ============================================================

import cds from '@sap/cds';
import * as metrics from '../lib/metrics.js';

const LOG = cds.log('kg-pagerank');

const CONCEPT_TABLE  = '"COM_SAP_DEVELOPERS_IMS_CONCEPTRANK"';
const TUTORIAL_TABLE = '"COM_SAP_DEVELOPERS_IMS_TUTORIALRANK"';

export async function runKgPageRank() {
  const t0 = Date.now();
  const db = await cds.connect.to('db');

  try {
    await db.tx(async (tx) => {
      await tx.run(`TRUNCATE TABLE ${CONCEPT_TABLE}`);
      await tx.run(`TRUNCATE TABLE ${TUTORIAL_TABLE}`);
      await tx.run('CALL "KG_PAGERANK"()');
    });

    const [{ N: conceptsScored }]  = await db.run(`SELECT COUNT(*) AS N FROM ${CONCEPT_TABLE}`);
    const [{ N: tutorialsScored }] = await db.run(`SELECT COUNT(*) AS N FROM ${TUTORIAL_TABLE}`);
    const durationMs = Date.now() - t0;

    metrics.observe('kg_pagerank_duration_ms', durationMs);
    metrics.gauge('kg_pagerank_nodes_scored', conceptsScored + tutorialsScored);

    LOG.info(
      `PageRank: ${conceptsScored} concepts, ${tutorialsScored} tutorials, ${durationMs}ms`
    );

    return { conceptsScored, tutorialsScored, durationMs };
  } catch (err) {
    metrics.counter('kg_pagerank_failures');
    LOG.error('PageRank job failed', err);
    throw err;
  }
}
```

- Same `t0 = Date.now()` at the top.

// ============================================================
// PageRank rank-map loader (#916).
//
// Reads ConceptRank and TutorialRank sidecar tables and returns
// { conceptRank: Map<slug, score>, tutorialRank: Map<slug, score>,
//   _normalizeTut(score): number }.
//
// Wrapped in a per-instance LRU with 5-minute TTL and a single-
// flight guard so concurrent neighborhood requests share the
// in-flight promise. Every fault path returns EMPTY_RANK_MAPS
// (fail-open — multiplier collapses to 1.0).
// ============================================================

const RANK_MAP_TTL_MS = 5 * 60 * 1000;

const _EMPTY_MAP = new Map();
const EMPTY_RANK_MAPS = Object.freeze({
  conceptRank: _EMPTY_MAP,
  tutorialRank: _EMPTY_MAP,
  _normalizeTut: () => 0,
});

let _rankMapsCache = null;      // { at: number, value: {...} }
let _rankMapsInFlight = null;   // Promise or null

async function _loadRankMapsFromDb() {
  const db = await cds.connect.to('db');
  const [conceptRows, tutorialRows] = await Promise.all([
    db.run('SELECT SLUG, SCORE FROM "COM_SAP_DEVELOPERS_IMS_CONCEPTRANK"'),
    db.run('SELECT SLUG, SCORE FROM "COM_SAP_DEVELOPERS_IMS_TUTORIALRANK"'),
  ]);

  const conceptRank  = new Map(conceptRows .map(r => [r.SLUG, Number(r.SCORE) || 0]));
  const tutorialRank = new Map(tutorialRows.map(r => [r.SLUG, Number(r.SCORE) || 0]));

  // Precompute min/max for O(1) normalization at call sites.
  let tMin = Infinity, tMax = -Infinity;
  for (const s of tutorialRank.values()) {
    if (s < tMin) tMin = s;
    if (s > tMax) tMax = s;
  }
  const range = tMax - tMin;
  const _normalizeTut = (range > 0)
    ? (s) => (s - tMin) / range
    : () => 0;

  return { conceptRank, tutorialRank, _normalizeTut };
}

async function loadRankMaps() {
  const now = Date.now();
  if (_rankMapsCache && (now - _rankMapsCache.at) < RANK_MAP_TTL_MS) {
    return _rankMapsCache.value;
  }
  if (_rankMapsInFlight) return _rankMapsInFlight;

  _rankMapsInFlight = (async () => {
    try {
      const value = await _loadRankMapsFromDb();
      _rankMapsCache = { at: Date.now(), value };
      return value;
    } catch (err) {
      metrics.counter('kg_pagerank_read_failures');
      // Fail-open. Do NOT cache the failure — next request retries.
      return EMPTY_RANK_MAPS;
    } finally {
      _rankMapsInFlight = null;
    }
  })();

  return _rankMapsInFlight;
}
