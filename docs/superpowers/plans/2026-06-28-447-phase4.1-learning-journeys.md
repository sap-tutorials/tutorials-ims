# Phase 4.1 Learning Journeys Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Learning Journeys as the first new graph node type under the Phase 4 architecture chassis. Cron fetches journey metadata from `sap-devs` MCP, scrapes journey bodies with tiered fallback, extracts `covers` and `journeyPrerequisite` relations via an LLM adapter, and surfaces journeys on Phase 3 concept landing pages + a new "Other resources" section on the tutorial-OP sidebar.

**Architecture:** Three stacked PRs: (1) chassis foundation — MCP client, TTL helper, GC cron, schema file, `extractConceptsCore` refactor, empty `otherResources` field; (2) Learning-Journey-specific code — body-fetcher, extraction adapter, cron job, projection helper, populates `otherResources`; (3) UI surfaces — concept-page section + sidebar section + telemetry.

**Tech Stack:** SAP CAP (Node.js 20), HANA Cloud, vitest (unit + hybrid), Hugo, Vue 3 islands.
