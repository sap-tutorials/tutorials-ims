# Accessibility

## Our commitment

The tutorial platform aims to be usable with assistive technologies — screen readers, keyboard-only navigation, browser zoom, and reduced-motion preferences. We build on the SAP Horizon design system, which has accessibility patterns built into every component, and we test the parts we customize on top of it.

## Standards we target

WCAG 2.1 AA.

> **Note:** target standards are placeholder pending project owner confirmation.

## Known issues

Open issues are tracked in GitHub with the `accessibility` label. If you'd like to see what's already on the list before reporting something new, look there first.

## How to report issues

Open an issue in the project repository, or use the feedback widget on any tutorial page and mention "accessibility" so it routes to the right team. Please include the page URL, your browser and assistive technology, and what you expected to happen.
